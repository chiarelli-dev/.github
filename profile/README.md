# Chiarelli Labs

Software sob medida com IA aplicada. Automatizamos processos, construímos agentes de IA e desenvolvemos aplicações internas e produtos digitais para empresas brasileiras.

## O que fazemos

- **Automação de processos**: elimina trabalho manual repetitivo integrando os sistemas que a empresa já usa
- **Agentes de IA**: assistentes que executam tarefas reais dentro da operação, com validação e telemetria
- **Aplicações internas**: ferramentas construídas para o processo da empresa, sem licença por usuário
- **Produtos digitais**: do escopo ao deploy, com stack moderna (TypeScript, Next.js, Postgres)

## Como trabalhamos

Todo projeto começa com uma Discovery: semana de imersão que entrega documento de escopo e proposta fechada de execução. Depois, entrega por marcos com escopo travado.
